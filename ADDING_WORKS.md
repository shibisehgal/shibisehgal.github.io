# How to add a new artwork to the website

It's drag-and-drop. You only ever touch **one Google Drive folder** — no spreadsheet,
no website code.

## Add a piece

1. **Drag the photo into the shared Drive folder.**
2. **Name the file what the artwork is called** — that becomes the caption on the site.
   - `Monsoon Sky.jpg` → shows as **Monsoon Sky**.

That's it. The website updates itself (within about an hour).

## Optional extras (only if you want them)

Add them right in the **file name**, separated by ` | ` (space-pipe-space):

```
Monsoon Sky | Soft pastel on paper | 2022.jpg
   caption          medium           year
```

- **Medium** — the bit after the first `|` (e.g. *Soft pastel on paper*).
- **Year/date** — the bit after the second `|`. If you leave it off, the site uses the
  date you uploaded the file.
- You can use just the caption, or caption + medium, or all three.

## Put a piece on the home page

Drop it into the **`Featured`** subfolder inside the main folder. Everything in the main
folder shows on the full **Gallery** page; anything in `Featured` *also* shows in the
"Latest works" strip on the home page.

## Editing & removing

- **Change a caption / medium / year:** just rename the file in Drive.
- **Remove a piece from the site:** delete the file from the Drive folder (or move it out).
- **Reorder:** ordering is newest-first by year, so the year controls the order.

## Tips

- Photograph artwork straight-on in good light; large photos are fine — the site shrinks
  and optimizes them automatically.
- Changes aren't instant: the site rebuilds on a schedule (about hourly). If you want it
  immediately, ask Atharva to hit "Run workflow" in GitHub, or just wait.
